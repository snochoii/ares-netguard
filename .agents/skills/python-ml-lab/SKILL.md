# Python ML Lab

Python remains the fastest path for PyOD, River, PyTorch, SHAP, Time-Series Foundation models, graph experiments, evaluation, and export.

Use this boundary for ML research, training, benchmark/evaluation prototypes,
synthetic fixture-based model reports, and non-exportable experimental models.
Do not promote Python sidecars into product runtime without documenting the
migration path in `docs/TECHNOLOGY_SELECTION_POLICY.md`.
